# 连续模拟交易与每日分钟因子研究修复

## 复盘结论

此前并非每天进程退出；10月19日进程持续运行，但执行核账112轮失败、分钟观察最长间隔约35分钟，且原风险暂停持续阻断交易。系统把不同原因混成了“没交易”，缺少可自动恢复的明确契约，这是本次修复的重点。

| 原因 | 旧行为 | 修复行为 |
| --- | --- | --- |
| 单日亏损达到2% | 持久暂停，退出持仓也被阻断 | 用户授权连续模拟后仅记警示；先核账再解除旧亏损暂停，保留亏损及峰值 |
| 持仓报价过期 | 整个执行轮次抛异常 | 连续模拟标记估值降级，逐单决定有效限价或授权股票市价；独立任务继续 |
| 执行异常与调度耦合 | 行情、资讯、分钟观察也被跳过 | 独立工作线程继续调度，执行状态如实降级 |
| 下单前检查失败 | 可能误记为结果未知 | 确定未提交或明确拒绝释放意图；已发出但回执不明仍先查单 |
| 清仓累计5次失败 | 后续永久不再尝试 | 连续模拟每批5次后退避5分钟；先确认没有工作中/未知订单再重新尝试 |
| 分钟模式关闭旧日线表达式 | 新因子停留在复盘文字 | Codex新分钟公式、独立源码、因果检查、回放和核账全部接入每日任务 |
| 没有候选通过盈利门槛 | 账户不能继续实验 | 用户授权的实验候选单独标记，失败检验保留，不冒充合格Alpha |

## 权限与资金

- 只使用已绑定的富途美股模拟账户及`/api/v1.0/sim-trade/`。没有实盘适配器。
- 股票/期权仍按90/10，保留全部订单、持仓、成本、资金流水、净值与风险峰值，不重置本金、不使用融资。
- `continuous_paper=true`、`stock_market_fallback=true`已由本次用户请求授权。
- 人工暂停、负现金、账户或持仓不一致、未知提交结果不按亏损恢复通道清除。普通读取失败不生成永久暂停。
- 正常交易时段股票可提交`order_type=3`市价单。买入需新鲜完整分钟信号、参考价10%预留缓冲及券商现金可买量核验；期权不扩大市价权限。预留价不是成交上限，最终以券商成交核账。
- 旧策略退出、T+1交收、资金交接继续使用持久化换仓流程。等待开市或交收是有下一步动作的业务状态，不是故障或无限期暂停。

## 每日收盘研究

收盘15分钟首次研究，60分钟核对数据修订。输入包含基线历史失败、复盘想法、带日期报价、首次可用时间的资讯标题与模拟持仓。只允许受限、向过去的分钟表达式，不执行模型任意代码。

每个数据版本最多一个新公式；执行代码修复可以重新验证同一公式，不能不断生成新假设挑最好看的历史结果。提案和验证分开检查点，模型或网络失败退避重试。科学淘汰也是完成的实验。

执行检查包括：完整收盘K、前缀不变、未来扰动、固定时间切分、30bps基础成本、50bps压力、额外一根K延迟、无因子配对对照和独立现金/持仓核账。未自动执行的额外文字反证单独标为NOT_RUN。历史反复被查看，不标为未见样本或未来Alpha。

## 实际挖掘

本轮Codex已生成`return_path_close_quality`，即最近三根K线的上涨路径效率减收盘回落压力，固定15分钟趋势和VWAP条件。

公式：`mean(returns,3) / mean(abs(returns),3) - mean(close_pressure,3)`。

因果检查通过，但验证/回顾收益为负，盈利、成本、延迟等检验失败，作为淘汰研究证据保留。最终数据、指标、源代码哈希和运行状态见runtime-evidence.json。它的生成不代表本轮选中了它交易；连续模拟按同版本验证结果择优，实验权限与盈利资格分开显示。

## 剩余业务事实

连续模拟表示服务、研究和符合条件的模拟订单持续运行，不等于每分钟一定成交。没有信号、市场关闭、资金交收中，仍可能无新买入；看板应显示具体原因。真正未知的提交结果必须先查单，不能为了“不断交易”重复下单。
