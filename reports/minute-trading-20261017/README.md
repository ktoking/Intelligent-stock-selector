# 2026-10-17 分钟策略与收盘恢复

## 为什么之前盘中没有新增股票订单

旧策略是日线信号、开盘五分钟内调仓；盘中60秒轮询只核账与风控。此前监控连续运行不等于盘中按分钟信号交易。这是旧实现与用户需要的交易周期不一致。量化并不限于分钟，但本次用户已经明确选择分钟周期。

## 本次实现

- 新研究默认使用真实Futunn 5分钟K线，15分钟确认，正常盘每60秒检查已完成的新K线，盘中有新判断可以提交模拟限价委托。没有把旧日线窗口直接放宽冒充分钟策略。
- 三类独立基线：开盘区间突破、VWAP回踩、趋势跟随。使用同一决定函数进行因果回放与前向判断；历史信号在下一根开盘假设成交，另加一根延迟压力检验。
- 回测与券商成交分别保存；分钟净值逐根估值并计算盘中回撤，不只用每日收盘低估回撤。全部成交使用整数股，最多2只、各20%净值，卖出资金T+1，不做空、不融资。
- 新版本通过历史门槛及同区间在任策略比较后，才走已有撤单、退出旧持仓、交收与资金交接。没有合格分钟候选时，旧日线停止新增调仓，按账户流程准备交接到现金。
- 原有股票/期权90/10资本和已发生亏损保留。本轮没有解除风险暂停；期权旧版本及历史链验证限制保留，不能说期权已改为分钟回测。
- 分钟读取在独立线程，订单仍在单一核账循环。幂等预留、未知回执、部分成交和资金约束沿用原账本；分钟委托使用创建后两分钟超时，而非开盘五分钟期限。
- 看板“运行 → 分钟策略实验室”新增覆盖、真实来源、验证/回顾/压力收益、失败门槛、最近观察和风险状态。
