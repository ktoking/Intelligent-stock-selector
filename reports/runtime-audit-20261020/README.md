## 确认的代码缺陷

serve把tick和后续独立工作线程的调度放在同一个try块中。tick对持仓过期报价抛异常后，直接进入最外层except，行情扫描、资讯、分钟观察及收盘研究的调度全部被跳过。因此一个持仓报价问题可以造成无关任务长时间失去调度机会。

## 本次修复

- 单独捕获执行核账异常，继续记录原异常与交易阻断，再调度独立工作线程。
- 原账户不一致、未知委托及风险暂停规则保留；不解除暂停、不降低报价门槛、不启用新策略或实盘。
- 本轮执行失败不被后续调度写成健康；休市空转也不把未恢复执行错误改写为健康。
- 未在本次修改中实现分钟新表达式生成，也未修改冻结策略或资金分配。
