# 每日方向简报

当前项目内置 `daily_direction` 子模块，用于每天生成“美股 + A股 + 港股”混合方向简报，并可推送到 SeaTalk 群 webhook 或当前 tunnel 机器人对应的 SeaTalk bot。

## 数据源

- 美股：`yfinance` 日线 OHLCV。
- 港股：`yfinance` 日线 OHLCV。
- A股：先用 `yfinance` 拉历史 K 线用于 MA/MACD/RSI/baseline，再用同花顺问财 `hithink-market-query` 覆盖最新一日的最新价、涨跌幅、成交量、开高低。若同花顺接口失败，则保留 `yfinance` 数据继续生成，不阻断日报。
- 资讯：基于候选股和大跌异动股拉取 `yfinance Ticker.news`，再补充 SPY/QQQ/ASHR/FXI/2800.HK 等市场代理标的新闻；同花顺 `wen-cai` 新闻接口当前实测版本不可用，暂不作为生产新闻源。
- 异动：来自三市场扫描结果中的 `top_signals`、`top_gainers`、`top_losers`，LLM 会结合资讯解释大涨/大跌可能触发因素。
- LLM：优先 GPT（存在 `OPENAI_API_KEY` 时），否则使用当前项目默认 Ollama。

## 手动运行

只打印，不推送：

```bash
.venv/bin/python scripts/daily_direction_push.py --test --no-llm
```

调用当前项目 LLM 配置生成总结：

```bash
.venv/bin/python scripts/daily_direction_push.py --test
```

实际推送到默认 SeaTalk bot 群：

```bash
.venv/bin/python scripts/daily_direction_push.py --send
```

通过已配置 tunnel 的 SeaTalk bot 主动推群：

```bash
export DAILY_DIRECTION_DELIVERY=seatalk-bot
export DAILY_DIRECTION_SEATALK_GROUP_ID="你的 group_id"

.venv/bin/python scripts/daily_direction_push.py --send
```

如果 `DAILY_DIRECTION_SEATALK_GROUP_ID` 为空，脚本会尝试使用 `SEATALK_ALLOWED_GROUP_IDS` 的第一个群 ID。

## LLM 选择

- 默认会加载 `.env` 和 `.env.local`。
- 若 `OPENAI_API_KEY` 存在，脚本默认优先把本次运行切到 `LLM_BACKEND=openai`。
- 若没有 GPT key，则沿用当前项目默认配置；本仓库当前默认是 `LLM_BACKEND=ollama` + `OLLAMA_MODEL=gemma4:31b-cloud`。
- 如果 LLM 调用失败，脚本会自动输出规则版方向，不阻断推送。

## Hermes 定时任务

Hermes 可以只负责调度，脚本自己生成内容并推送。当前只保留工作日 9 点推送到 SeaTalk bot 群：

```bash
DAILY_DIRECTION_DELIVERY=seatalk-bot
DAILY_DIRECTION_SEATALK_GROUP_ID="你的 group_id"
```

再创建 Hermes 定时任务：

```bash
hermes cron create "0 9 * * 1-5" \
  --name "stock-agent 每日方向简报" \
  --workdir /Users/kaiyi.wang/PycharmProjects/stock-agent \
  --script /Users/kaiyi.wang/PycharmProjects/stock-agent/scripts/daily_direction_hermes_job.sh \
  --no-agent
```

手动触发一次 Hermes job 可用：

```bash
hermes cron list
hermes cron run "stock-agent 每日方向简报"
```

如果希望 Hermes 再二次整理脚本输出，可以去掉 `--no-agent`，并在 prompt 里要求“保留标的和风险，只压缩成群消息”。第一版建议使用 `--no-agent`，稳定性更好。

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `--markets us,cn,hk` | 选择市场，默认三市场都扫 |
| `--max-items 15` | 每个市场进入 LLM 总结的 baseline Top N，默认 15 |
| `--test` | 每个市场只扫少量标的，用于验证 |
| `--no-llm` | 不调用 LLM，直接使用规则版 |
| `--send` | 实际推送 SeaTalk |
| `--delivery webhook/seatalk-bot` | 选择群 webhook 或 SeaTalk bot OpenAPI |
| `--webhook-url` | 覆盖 `DAILY_DIRECTION_WEBHOOK_URL` |
| `--signing-secret` | 覆盖 `DAILY_DIRECTION_SIGNING_SECRET` |
| `--sign-mode auto/query/none` | 默认 `auto`，先尝试带签名，失败后降级无签名 |
| `--group-id` | 覆盖 `DAILY_DIRECTION_SEATALK_GROUP_ID`，仅 `seatalk-bot` 使用 |
| `--thread-id` | 可选，指定 SeaTalk thread |
