# 快速因子与 SOXL 候选研究 · 2026-09-05

本轮找到一条进入目标历史年化区间的**待验证候选**：`SOXL_ema20_100_vol60`。2013-04-24 至 2026-06-05，3,300 个交易日的净年化为 **41.59%**；提高至往返 40bp 成本后仍为 **40.66%**。但最大收盘回撤 **62.76%**，最近 63 日亏损 **7.54%**，尚未得到前向验证。目标继续研究，未标记完成。

## 新一批因子

TQQQ / UPRO 分别使用 QQQ / SPY 的收盘信号：MA50、MA100、EMA10/50、EMA20/100、20/10 与 55/20 日通道突破、20 日与 63 日时间动量、下行波动门槛、五个趋势信号的固定平均组合。每个因子对比全额仓位、40% / 60% 年化波动目标，共 60 个配置。

通道阈值来自前一日及更早的价格，当前收盘可触发突破；波动目标使用实际杠杆 ETF 前 20 日收益波动。账户无借款，但基金内含杠杆。预热 253 日，每轮 252 日训练、63 日验证、63 日测试，共 53 段。前一日收盘生成权重、下一日开盘交易，每边成本 7bp，压力情景为 12.5bp / 20bp。

收益优先选择器最大化训练/验证较弱一段的年化，不设置未获用户确认的回撤硬上限，也不因近期策略都表现不佳而把整个季度锁定为空仓。另行对比 Calmar 优先选择器。

## 参数不变的跨标的迁移

在观察迁移结果前登记三条规则：EMA20/100 + 60% 波动目标、EMA10/50 + 60% 波动目标、20 日动量 + 40% 波动目标。分别迁移到 SOXL（信号代理 SMH）、TECL（信号代理 XLK），不重新调参。新下载四只 ETF 从 2012-01-03 至 2026-09-04 的完整日线，各 3,690 个交易日。

| 规则 | 长期净年化 | 最大收盘回撤 | 最近63日净收益 |
|---|---:|---:|---:|
| SOXL_always_full | 55.84% | 90.46% | -44.39% |
| SOXL_ema20_100_vol60 | 41.59% | 62.76% | -7.54% |
| SOXL_ema10_50_vol60 | 29.81% | 63.56% | -18.52% |
| SOXL_momentum20_vol40 | 20.62% | 49.42% | 2.42% |
| TECL_always_full | 48.04% | 77.96% | -6.06% |
| TECL_ema20_100_vol60 | 38.48% | 57.59% | 2.27% |
| TECL_ema10_50_vol60 | 24.69% | 54.63% | -14.00% |
| TECL_momentum20_vol40 | 20.42% | 42.41% | -1.60% |

候选规则的精确定义：

1. SMH 复权收盘的 EMA20 > EMA100 时允许持有 SOXL；EMA 使用 `adjust=False`。
2. 目标权重 = `min(1, 0.60 / (SOXL前20日日收益样本标准差 × sqrt(252)))`；趋势不成立时权重为零。
3. 每日收盘重新计算，次日开盘调仓；根据可用现金先卖后买，不借款。
4. 使用 SOXL 真实历史价格路径，不能把 SMH 收益乘三当成 SOXL 收益。

SMH 跟踪 MVIS US Listed Semiconductor 25 Index，SOXL 当前跟踪 NYSE Semiconductor Index 的每日三倍目标；所以 SMH 是行业信号代理，并非精确基准。[SMH 官方资料](https://www.vaneck.com/us/en/investments/semiconductor-etf-smh-fact-sheet.pdf)、[SOXL 官方资料](https://www.direxion.com/product/daily-semiconductor-bull-bear-3x-etfs)

SOXL 的投资基准在 2021-08-25 前后发生变更，不能将整段历史视为完全不变的基准定义。[SEC 基金说明](https://www.sec.gov/Archives/edgar/data/1424958/000119312525039961/d867564d497k.htm) 按该日期拆开连续组合收益，前后年化分别为 **40.23% / 43.99%**。这只是结构变更前后的归因，未改变规则，也不是新的独立验证。

## 候选的收益与风险检查

| 情景 | 长期净年化 | 最大收盘回撤 |
|---|---:|---:|
| 正常次日开盘、往返14bp | 41.59% | 62.76% |
| 往返40bp | 40.66% | 63.11% |
| 再延迟一个交易日 | 42.17% | 65.56% |
| 再延迟两个交易日 | 40.72% | 60.66% |
| 再延迟一日且往返40bp | 41.22% | 65.90% |

- 最差单日 **-18.89%**；最长连续低于此前历史高点 **598 个交易日**。
- 日均几何收益 **0.138%**；3,300 日中 **841 日达到 +2%（25.48%）**，没有每天赚 2% 的证据。
- 去掉收益最好的 5 / 10 / 20 日，年化分别降至 **34.90% / 29.58% / 20.48%**。这是事后集中度压力测试，不能把这些天当作可预知而跳过的交易日。
- 连续 5 日块 bootstrap 共 3,000 次，条件年化 95% 区间约 **[5.36%, 92.89%]**；没有校正此前因子/标的选择，不能解释为未来收益承诺或真实概率。
- 按当时前 20 日成交额中位数估算，最大委托约占日成交额 **1.45%**，有 3 条委托超过 1%。这是日成交额代理，不证明开盘竞价深度足够。
- 2022 年实际组合亏损 **41.65%**，2024 年亏损 **16.03%**；总体年化无法代替年度风险。

## 独立会计与代码验证

17 个针对性测试通过，包括未来数据扰动不改变历史信号/权重、通道不能使用当前价格抬高突破阈值、权重/现金约束，以及数组引擎与原现金引擎在多标的、不同成本和调仓周期下逐日一致。

另外将 **1,761 条冻结 SOXL 委托**交给 Backtesting.py 的 FractionalBacktest 独立经纪账本重放：

- 原引擎终值：9,499,222.49290118 美元；独立引擎：9,499,222.492965654 美元。
- 终值差 **0.000064 美元**，逐日最大净值差 **0.000108 美元**，无拒单警告。
- 第一版以 1e-6 股为精度时发生一条取整边界拒单，失败报告已保留。最终使用 1e-8 股精度，并加固定 0.01 美元取整缓冲；比较每个净值前均扣除该缓冲，没有调整原始委托数量来追收益。
- 终值收盘平仓用一个价格不变的结算条表示，不增加投资收益。
- 这验证冻结委托的成交会计、费用和逐日估值，**不是重新独立验证信号因果性或真实可成交性**。

第二行情来源 Stooq 返回 HTTP 200 的 HTML 验证页面，没有取得 CSV。价格与复权仍未完成跨供应商复核。不能把会计吻合冒充独立行情验证。
