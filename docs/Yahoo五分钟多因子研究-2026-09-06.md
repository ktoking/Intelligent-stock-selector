# Yahoo 5分钟多因子研究：第一轮

结果：未达收益目标，本轮组合不进入模拟跟踪。已按用户要求采用Yahoo 5分钟数据，暂不等待富途登录。

## 数据与划分

- SOXL、TQQQ交易标的，SMH、QQQ提供参考趋势。每个标的3,198根5分钟K线，2026-07-10至2026-09-04，共41个完整正常交易日。按交易所日历检查缺失和重复，未填补缺失价格。
- 这是近期分钟数据试验，尚未覆盖一年。5天用于初始化；22天训练（7月17日至8月17日），7天验证（8月18日至26日），最后7天检验（8月27日至9月4日）。
- 最后7天在本轮参数选择落盘之后才评估。但此前日线研究已观察过同一市场时期，不能声称完全独立于此前所有研究。

## 因子与成交规则

五项因子：已完成15分钟K线的EMA9/21趋势、当日VWAP位置、相对过去同时段成交量、RSI动量区间、参考ETF的15分钟趋势。对比突破、回踩和评分上升三种入场方式，评分门槛3/4，以及每次计划风险0.5%/1%，共12组。

只用已收盘信号，下一根5分钟K线开盘执行。数量根据上一根收盘价和3%限价预算提前计算；买单超过限价不成交。一个账户同时最多一笔持仓，每天最多3笔，日终平仓，不外加杠杆。止损采用1.5倍ATR、止盈2R；同根K线同时碰止损和止盈时优先记止损，止损跳空按更差开盘价。

基础假设为每边7bp费用、2bp滑点（合计往返约18bp）；压力费用每边15bp。收盘观察到当日账户收益达到+2%或-2%时停止开新仓，持仓下一根开盘退出，因此不能保证恰好锁定2%或把亏损限制在2%。允许复用卖出后的购买力，未模拟严格现金账户的资金交收限制；成交深度、最小收费和税务也未验证。

## 结果

12组在验证段全部亏损。预先写定的排序规则选中`breakout_score3_risk100`（相对最好，不代表达标）。

|区间|交易日|净收益|交易数|盈利达到2%的天数|
|---|---:|---:|---:|---:|
|训练|22|0.40%|31|3|
|验证|7|-0.82%|11|1|
|最终检验|7|-1.57%|11|0|

最终检验的5分钟收盘净值最大回撤为3.83%，胜率27.27%。机械年化折算为-43.35%，但7天远不足以验证年化收益；不把这项短期折算作为年度业绩。提高费用后的最终净收益为-2.79%。

## 成本与因子诊断

|区间|零费用、零滑点|基础费用与滑点|
|---|---:|---:|
|训练|3.33%|0.40%|
|验证|0.77%|-0.82%|
|最终检验|-0.07%|-1.57%|

成本吃掉了训练与验证段的一部分毛收益，但最终段即使零成本也没有盈利。费用变化可能触发不同的日内暂停和后续交易，因此这是成本场景对照，不是精确加法归因。

仅在训练段检查各因子与随后30分钟毛收益的关系：相对放量和适中正动量值得继续研究；综合评分升高与收益并不呈单调关系。SOXL的慢趋势过滤在该训练段可能滞后，不能据此直接反转成做空信号。相关样本相互重叠，未经多重检验校正，不能将分组平均收益当成可执行策略收益。完整分组数据保存在`diagnostics.json`。
