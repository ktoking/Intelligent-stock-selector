# Yahoo五分钟：行情分类与反弹因子

2026-09-06。新增16组固定假设，沿用四个ETF的41个完整交易日和相同现金账户成交引擎。上一轮完成了12组回测，本轮是新的因子实验；所有区间此前已看过，仅作为历史诊断，收益目标仍未达成。

## 因子组合

四类信号：价格偏离VWAP后开始回归；VWAP下方的超跌转强；低趋势效率区间的下沿反弹；高趋势效率时的均线回踩。前三类要求参考ETF当日跌幅不超过1.5%，并有价格转强确认；趋势回踩要求标的和参考ETF的已完成15分钟趋势均向上。分别比较有无同时段相对成交量≥1.2的过滤，以及0.5%/1%的每笔计划风险。

保持每边7bp费用＋2bp滑点、下一根K线成交、一个共享账户最多一笔持仓、每天最多3笔、日终平仓、1.5ATR止损与2R止盈。同K线歧义优先止损，跳空止损按更差开盘价；成交深度和严格现金交收尚未建模。未修改上一轮已冻结的结果或交易引擎。

## 选择与结果

选择标准提前固定：训练至少10笔、验证至少3笔，最大化训练/验证中较低的日Sharpe。选中`range_bounce_volume_risk100`：区间反弹＋相对放量，计划风险1%。该排序只选相对最好者，不等同于通过盈利门槛。

## 日收益2%与交易结构

训练段有8天未交易，验证段有4天未交易。当前组合的择时频率本身就无法产生每天2%的结果。对训练信号按固定2R止盈做示意计算，SOXL单笔满止盈的账户净贡献中位数约1.89%，TQQQ约1.27%（未进一步扣除3%预留的仓位影响）；这要求实际能触及目标并成功成交，不能解释为必然收益或日收益上限。不能仅把止盈设置成2%，就认为账户每天会赚2%。
