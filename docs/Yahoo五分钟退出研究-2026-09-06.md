# Yahoo五分钟：固定入场、比较退出方式

2026-09-06。本轮固定此前两个入场组合，比较15/30/60分钟和日终退出，以及保留/取消2R止盈，共16组。所有组合始终保留止损、单账户单持仓、每笔预算、每日交易次数限制与费用滑点；没有删除风险控制来美化收益。此前历史已观察，本轮没有新的独立样本。

## 结论

相对较好的是“区间反弹＋放量确认，不设固定止盈，保留止损及日终平仓”。15或30分钟强制退出对该入场规则的训练表现更差；延长持仓值得后续检验，但目前净收益未达目标。

|区间|交易日|净收益|日收益≥2%的天数|
|---|---:|---:|---:|
|训练|22|-0.022%|1|
|验证|7|1.604%|1|
|已观察末段|7|-0.037%|0|
|连续全区间（事后诊断）|36|1.543%|2|

连续36日机械年化为11.32%，5分钟收盘净值最大回撤4.99%。这是挑选后同一历史的诊断，不能当作实际年度收益。提高每边费用至15bp后，全区间收益为-1.51%。

单独验证段7天收益1.60%所折算的77.31%年化不能用来宣告达标：训练段基本持平，末段依然微亏。全区间每天达到2%的目标没有实现。

## 方法

入场固定为上一轮的突破组合和区间反弹放量组合；选取仍只根据22天训练和7天验证、最低交易笔数及两段中较低的日Sharpe，选择先落盘再检查已观察末段。持仓计时从实际入场K线开始，15分钟退出在入场后第3根5分钟K线开盘执行，不使用那根尚未形成的收盘价。若此前触及止损或启用的止盈，先退出。

下一根开盘成交、3%限价预留、每边7bp费用＋2bp滑点、单账户最多一笔持仓等原有假设保持。买卖资金复用、固定滑点和全部成交仍属模拟假设；没有接入真实账户。
