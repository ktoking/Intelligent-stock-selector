# moomoo 导入说明

1. 在 moomoo 桌面端的量化策略管理中导入 `SOXL_SOXS_QQQ_TREND_SWITCH_V1.quant`。
2. 将唯一运行标的绑定为 `US.QQQ`。
3. 使用每 5 分钟触发；策略内部只会在美东时间 09:35～09:59 每日执行一次。
4. 回测时把 `execution_enabled` 改为 `True`；模拟观察或实盘 Shadow 时保持默认 `False`。
5. 默认参数为 QQQ 已完成日线的 2 日动量：大于 `+2%` 持有 SOXL，小于 `-2%` 持有 SOXS，中间区域持币；目标资金比例 `95%`。

策略切换时先卖出原 ETF，确认成交后才买入另一只；不会有意同时持有 SOXL 与 SOXS。若卖单在约 2 秒内未确认成交，本轮不买入，等待下一次运行，避免双持仓。

该文件是 moomoo 可导入的 Python 代码型 `.quant`，不是附件那种可视化积木二进制工程。导入兼容性仍应在你的 moomoo 版本中做一次回测验证。
