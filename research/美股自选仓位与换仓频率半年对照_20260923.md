# 美股自选日 K：仓位与换仓频率对照

日期：2026-09-23。性质：事后参数消融，仅为模拟回测；没有 OpenD、富途软件操作或真实／模拟账户下单，也不是历史 AI 决策回放。用户提出“仓位更重、操作更频繁”后，先固定以下 2×3 组合，再统一运行。

## 固定规则与变体

全组均使用当前美股自选池中的普通股票（数据完整者 155 只；行情覆盖 220 只），QQQ 昨日收盘高于 EMA100 才允许新开仓；候选股须收盘高于 EMA50 且 EMA50 高于 EMA150、63 日动量为正、股价和流动性达标，按动量／20 日波动率排序，最多 5 只。个股跌破 EMA50 或较持有期峰值跌 15% 后次日开盘卖出。每天只读已完成日 K，按下一交易日的富途 REST 前复权开盘价模拟成交。初始资金 10,000 美元，现金约束、整数股、无借贷。

- 原仓位：单票上限 20%，目标 `min(20%, 1% / 日收益波动率)`；重仓：上限 30%，目标 `min(30%, 1.5% / 日收益波动率)`。这是单票权重增加，不是保证总仓始终满仓。
- 换仓触发：周一；周一和周四；每个交易日。无论哪档，个股风控卖出检查仍是每日进行。
- 每笔买、卖各扣 10 或 25 基点的合并摩擦假设。没有另加佣金最低额、分红、税费、借券、真实盘口容量或开盘冲击。

## 每边 25 基点：两段连续半年对照

每格为“总收益 / 最大回撤 / 订单数”；每段均为 127 个交易日。2025 区间是回顾性诊断，不是独立样本外验证：目前的自选池和策略研究过程均已受后见信息影响。

| 单票仓位 × 换仓触发 | 2025-03-24—09-23 | 2026-03-23—09-22 |
|---|---:|---:|
| 原仓位 × 周一（冻结基线） | +41.50% / 7.49% / 83 | +30.52% / 14.63% / 91 |
| 重仓 × 周一 | +48.35% / 8.76% / 73 | +32.82% / 14.88% / 86 |
| 原仓位 × 周一、周四 | +39.09% / 9.43% / 123 | +39.46% / 14.59% / 131 |
| 重仓 × 周一、周四 | +46.33% / 12.31% / 112 | +55.91% / 15.33% / 119 |
| 原仓位 × 每日 | +43.14% / 7.81% / 177 | +18.80% / 19.76% / 189 |
| 重仓 × 每日 | +35.35% / 10.06% / 151 | +19.41% / 23.55% / 185 |

“重仓＋周一、周四”在 2026 半年比基线多 25.39 个百分点收益，最大回撤多 0.70 个百分点，订单数多 28；但在 2025 半年只多 4.83 个百分点收益，回撤多 4.82 个百分点。2025 的风险收益权衡并不突出。相反，“重仓＋周一”两段均提高收益且只小幅增加回撤，是较稳健的**后续模拟候选**，而非已证实能在未来两个月盈利的版本。每日换仓在最近半年显著拖累收益并放大回撤；不能把“更频繁”本身视为优势。

摩擦敏感性同样明显：2026“重仓＋周一、周四”在每边 10 基点为 +61.85% / 13.98%，提高到 25 基点后为 +55.91% / 15.33%；2025 同一策略则从 +51.22% / 12.27% 降为 +46.33% / 12.31%。这是模拟成交与参数设定下的净值变化，不等于可实际成交收益。

## 校验与限制

- 新程序的“原仓位 × 周一”在两段、两档摩擦下，其订单与逐日净值都与冻结的 `watchlist_daily_trend.simulate` 完全一致。重仓＋每周两次的逐日现金、股数、净值已由订单账本重新核对，现金未为负；截断未来行情后，截断日前的订单及净值不变。对应测试 4 个通过。
- 数据来自本地缓存的富途 REST 前复权日 K；没有在本轮重新抓取。当前自选池回看历史存在幸存者／选择偏差；且 2026 区间此前已查看过，六组变体也不构成独立样本外证据。年化数字在这种短窗口会误导，因此主表只给区间总收益。
- 若继续进行未来两个月的纸面跟踪，应事先冻结“重仓×周一”作为低换手候选，同时保留冻结基线；“重仓×周一、周四”可作为另一个并行影子候选。每日收盘后记录信号、次日实际可成交价与全部成本；每周复盘可以提出新规则，但不回写已冻结的规则。没有自动执行或量化文件推广。
