Codex CLI 如何工作

Python 收集富途数据、因子目录、已有实验和风险约束，调用一次 Codex CLI。分析结果通过 JSON schema 校验，再交给 Python 注册候选与回测。每天复盘是另一次独立调用。

codex exec --ignore-user-config --ephemeral
--model gpt-6.1-sol -c model_reasoning_effort=high
--sandbox read-only --output-schema schema.json -

显式指定 gpt-6.1-sol / high；240 秒超时。读取 CLI 运行头核验实际设置。输入仅含整理后的证据，输出经 schema 校验。受限表达式生成新因子代码，每个新版本重新验证。私人简报按当天候选、跨市场行情与带时间戳资讯生成，具体标的和证据引用均校验。

01

开盘前 10 分钟行情、夜盘、财报资讯与宏观日历；Codex解读。前2分钟刷新事实，前5分钟账户预检

02

正常交易时段订单和风控每 60 秒；广池每 5 分钟；重点标的推送；资讯每 30 分钟。分钟版本每根完整5分钟K评估；日K与分钟K共同择优，选中日K时仍按原规则调仓

03

收盘后封存 Shadow；15 分钟后更新、研究和复盘，60 分钟后再次核对日线

04

休市 / 周末保留网页与本地调度；无正常行情轮询。未完成订单仍需核对

电脑本机 LaunchAgent 托管，服务已有防闲置系统休眠保护；关机或手动休眠仍会中断。未创建 Codex Work 定时任务。
